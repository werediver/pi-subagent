# Pi Subagent Extension

## Extension design

The extension design is described in [DESIGN.md](./docs/DESIGN.md), [DESIGN_REUSE.md](./docs/DESIGN_REUSE.md).

## Naming conventions

Do not use the word "subagent" to refer to the extension itself, use "extension" instead (e.g. `ExtensionConfig` for the extension configuration, not `SubagentConfig`).
